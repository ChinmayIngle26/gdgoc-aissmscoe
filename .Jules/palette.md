## 2024-05-18 - Framer Motion Keyboard Accessibility and Redundant ARIA

**Learning:** When UI elements use Framer Motion's `whileHover` to reveal descriptive text or expand their size, keyboard-only users will miss this context unless `whileFocus` is also explicitly provided. Additionally, when a parent interactive element (like `motion.a`) has a comprehensive `aria-label`, child elements like decorative icons or images should use empty alt text (`alt=""`) and `aria-hidden="true"` to prevent screen readers from redundantly announcing the image description and the link's label.
**Action:** Always pair Framer Motion's `whileHover` with `whileFocus` for interactive elements to ensure keyboard accessibility. Combine this with Tailwind's `focus-visible:ring-2 focus-visible:outline-none` for clear visual focus indicators. Always empty the `alt` attribute and hide decorative nested SVGs/images from screen readers when the parent container already provides the full context via `aria-label`.
