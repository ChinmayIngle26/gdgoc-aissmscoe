## 2024-05-24 - Floating Social Links Accessibility & UX Polish
**Learning:** Animated flex containers using Framer Motion require explicit `shrink-0` on fixed-size child elements (like icons) to prevent squashing during transition. Additionally, wrapping floating interactive elements in a fixed div can create an invisible bounding box that blocks interactions on underlying content, unless `pointer-events-none *:pointer-events-auto` is applied to the wrapper. Finally, interactive components with explicit `aria-label`s should apply `alt=""` and `aria-hidden="true"` to purely decorative nested elements to prevent redundant announcements.
**Action:** When creating fixed floating UI containers, always apply pointer-events utilities to ensure transparent boundaries are unclickable. Pair `whileHover` with `whileFocus` for Framer Motion elements to guarantee keyboard accessibility.
