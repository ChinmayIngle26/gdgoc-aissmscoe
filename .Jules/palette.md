## 2024-06-01 - Floating Action Buttons & Screen Reader Redundancies
**Learning:** Fixed overlay containers for floating UI components (like social links) often have invisible bounding boxes that inadvertently block click events on the underlying page content. Additionally, when using Framer Motion on interactive elements, `whileHover` animations are not accessible via keyboard navigation unless explicitly paired with `whileFocus`. Finally, decorative icons within elements that already have an `aria-label` cause redundant and annoying screen reader announcements if not explicitly hidden.
**Action:** Apply `pointer-events-none` to the parent fixed container and `*:pointer-events-auto` to its children so only the visible buttons intercept clicks. Always pair `whileHover` with `whileFocus` on Framer Motion interactive elements, and add `focus-visible:ring-2 focus-visible:outline-none` for visual focus indication. Apply `alt="" aria-hidden="true"` to purely decorative or redundant images inside elements that possess descriptive `aria-label`s.
