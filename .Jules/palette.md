## 2024-06-09 - Accessible Framer Motion Components & Interactive Flex Containers
**Learning:** Fixed flex containers mapping bounding boxes over interactive content below can block underlying interactions without visually indicating it. Furthermore, Framer Motion interactive `whileHover` animations do not trigger automatically on keyboard focus unless explicitly paired with `whileFocus`. Finally, purely decorative child images within a container that already has an explicit `aria-label` get announced redundantly by screen readers if not hidden.
**Action:** Always apply `pointer-events-none *:pointer-events-auto` to fixed flex containers. Always pair Framer Motion's `whileHover` with `whileFocus` for keyboard accessibility, and ensure a clear focus indicator is present (e.g., `focus-visible:ring-2`). Always apply empty alt text (`alt=""`) and `aria-hidden="true"` to purely decorative images within `aria-label` elements.
