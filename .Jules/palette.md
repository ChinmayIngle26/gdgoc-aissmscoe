## 2024-06-04 - Fixed Container Click Targeting & Image Aspect Ratio during Transitions
**Learning:** When using fixed flex containers for floating interactive elements (like social button overlays), the container's bounding box can invisible block clicks on the underlying page content. Also, width animations on flex containers will squash inner icons unless explicitly prevented. Additionally, Framer Motion's `whileHover` interactions are inaccessible via keyboard unless explicitly paired with `whileFocus` and focus indicators.
**Action:** Always apply `pointer-events-none *:pointer-events-auto` to fixed wrapper containers. Apply `shrink-0` to images within dynamically sized flex wrappers. Always pair `whileHover` with `whileFocus` and add `focus-visible:ring-2 focus-visible:outline-none` for keyboard navigation visibility.
