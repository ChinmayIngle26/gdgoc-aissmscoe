## 2024-03-24 - Make interactive Framer Motion components accessible
**Learning:** Elements using `whileHover` for crucial visual states (like expanding to reveal text) are entirely missed by keyboard users unless paired with `whileFocus`. Additionally, purely decorative icons within `aria-label` links create redundant screen-reader announcements unless specifically hidden (`alt=""` and `aria-hidden="true"`). Lastly, when creating multiple similar buttons, it is easy to accidentally copy-paste `aria-label` attributes resulting in misleading text for screen readers.
**Action:** Always check `whileHover` components for a corresponding `whileFocus` state. Add `alt="" aria-hidden="true"` to purely visual children of components that already provide an accessible name. Double-check `aria-label`s for accuracy.
