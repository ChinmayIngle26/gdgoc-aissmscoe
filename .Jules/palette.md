## 2024-05-15 - Interactive Framer Motion Components Accessibility
**Learning:** This design system heavily uses Framer Motion's `whileHover` for interactive scale animations on buttons/links (like social icons). However, these are often missing `whileFocus` counterparts and visible focus rings, making the app's interactive elements feel "dead" and inaccessible to keyboard users. In addition, copy-pasting these components often leads to incorrect `aria-label`s.
**Action:** When adding or auditing Framer Motion interactive components, always enforce the pattern of pairing `whileHover={{ scale: 1.1 }}` with `whileFocus={{ scale: 1.1 }}` and append Tailwind's `focus-visible:ring-2` (and appropriate ring colors) to ensure keyboard navigation triggers the same delight and visibility as mouse interaction. Double-check `aria-label` values for copy-paste errors.
