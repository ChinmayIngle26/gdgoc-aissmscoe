## 2023-10-27 - Floating Social Buttons Accessibility
**Learning:** Copy-pasting interactive components like floating buttons frequently leads to incorrect `aria-label`s remaining on subsequent buttons (e.g. LinkedIn button labeled "Join Whatsapp Group"). Furthermore, Framer Motion components relying on `whileHover` for revealing tooltips/text are inaccessible to keyboard users unless explicitly paired with `whileFocus`. Finally, decorative icons inside buttons that already have `aria-label`s must have `alt=""` and `aria-hidden="true"` to prevent redundant screen reader announcements.
**Action:** Always verify `aria-label` values after copying components. Always pair `whileHover` with `whileFocus` for Framer Motion interactive elements, and add Tailwind focus rings (`focus-visible:ring-2`) to ensure keyboard users can discover the same expanding animations as mouse users.
