## 2024-06-16 - Interactive Floating Button Accessibility
**Learning:** Floating action buttons (like Discord, LinkedIn, Whatsapp) in this repo use Framer Motion's `whileHover` to expand and reveal text. However, they lack `whileFocus` bindings, making the text expansion inaccessible to keyboard users. Additionally, the aria-label on the LinkedIn button was incorrectly copy-pasted ("Join Whatsapp Group").
**Action:** When implementing expandable icon buttons with `whileHover`, always pair it with `whileFocus` to ensure feature parity for keyboard navigation, and apply `focus-visible` Tailwind classes for visual focus rings. Also, verify `aria-label`s are unique and accurate, and apply `alt=""` and `aria-hidden="true"` to purely decorative icon images inside elements that already have an `aria-label`.
