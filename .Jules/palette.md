## 2024-05-24 - Social Button Accessibility and Layout Insights
**Learning:** Framer Motion `whileHover` animations do not automatically provide keyboard focus equivalents, rendering expanded states inaccessible to keyboard navigation. Flex layout transitions can squash inner images if `shrink-0` is omitted. Existing explicitly labeled interactive elements (`aria-label`) cause redundant screen reader announcements if their inner decorative SVGs/images lack empty alt text and `aria-hidden="true"`.
**Action:** Consistently pair `whileHover` with `whileFocus` for Framer Motion components, include visual focus indicators (e.g., `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-offset-2`), apply `shrink-0` to images within animated flex layouts, and use `alt=""` alongside `aria-hidden="true"` for decorative graphics within explicitly labeled controls.
