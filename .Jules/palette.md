## 2024-05-18 - Component Keyboard Accessibility and Squashing Images
**Learning:** When using Framer Motion's `whileHover` for interactive elements (like social links), we must also pair it with `whileFocus` to ensure keyboard navigators experience the same state changes. Also, adding `focus-visible:ring-2 focus-visible:outline-none` provides a clearer focus indication. Finally, for `img` tags inside `flex` containers that animate width changes, using `shrink-0` prevents the image from squashing during the transition. If the parent container acts as a button/link with an `aria-label`, decorative images inside should use `alt=""` and `aria-hidden="true"`.
**Action:** Always verify `whileFocus` is present alongside `whileHover`, use `shrink-0` on images inside expanding flex containers, and hide redundant child elements from screen readers.
