## 2024-06-03 - Framer Motion & Tailwind A11y
**Learning:** Fixed positioning components wrapping Framer Motion animations with hover capabilities need `whileFocus` to replicate interactions for keyboard users. Adding visual feedback like `focus-visible:ring-2` combined with `focus-visible:outline-none` on standard motion elements bridges the gap between Tailwind focus and JS hover interactions smoothly. Combining this with a `pointer-events-none *:pointer-events-auto` flex container resolves overlapping invisible hitbox issues gracefully.
**Action:** Always replicate `whileHover` interactions with `whileFocus` when building accessible interactive widgets, and group them with flex containers passing specific pointer events downwards rather than manual absolute offset values.
