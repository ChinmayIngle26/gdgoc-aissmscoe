## 2024-11-20 - Social Overlays and Framer Motion Accessibility
**Learning:** Fixed overlay containers (like social button groupings) often create invisible bounding boxes that block clicks on underlying page content. Additionally, `framer-motion`'s `whileHover` interactions aren't automatically accessible via keyboard navigation, leading to a degraded experience for users relying on tab focus. Child icons within interactive elements with an `aria-label` cause redundant and annoying screen reader announcements if they lack `aria-hidden`.
**Action:** Use `pointer-events-none` on the fixed overlay container and `*:pointer-events-auto` on the child elements. Always pair `whileHover` with `whileFocus` for Framer Motion components, along with `focus-visible:ring-2 focus-visible:outline-none` for visual focus. Use `alt="" aria-hidden="true"` for decorative SVGs/images inside labeled interactive components.
