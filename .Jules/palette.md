## 2024-05-08 - Interactive Framer Motion Components Accessibility
**Learning:** When using Framer Motion's `whileHover` to reveal hidden elements or change bounds for interactive elements (like a link or button expanding to show text), it is critical to pair it with `whileFocus` to ensure the same reveal or expansion happens for keyboard users navigating via Tab. Furthermore, copy-pasting similar components (e.g., social buttons) often leads to incorrect `aria-label`s or `alt` attributes which must be rigorously checked. External links should always have `target="_blank"` paired with `rel="noopener noreferrer"` for security, and decorative images inside interactive elements should have `alt=""` and `aria-hidden="true"`.
**Action:** Always test interactive Framer Motion components with keyboard navigation (Tab key). If `whileHover` is used for UX reveals, add `whileFocus` with the identical parameters. Double check `aria-label`s when duplicating components to avoid screen reader confusion.
