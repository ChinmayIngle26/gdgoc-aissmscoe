## 2024-03-24 - Accessible Framer Motion Transitions
**Learning:** When building or modifying custom interactive elements (like Framer Motion hamburger menus or toggles), explicit accessibility states (`aria-expanded`, `aria-controls`, and dynamic `aria-label` like 'Open menu' vs 'Close menu') must be strictly tied to the React state variables that control the visual transitions. Additionally, interactive animation triggers like `whileHover` should always be paired with `whileFocus` to ensure the same affordance is available via keyboard navigation.
**Action:** Always map state-driven animations to corresponding `aria-*` attributes, ensure containers have matching IDs for `aria-controls`, and pair hover animations with focus equivalents and explicit `focus-visible` styling.
