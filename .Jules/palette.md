## 2024-06-22 - Floating Social Buttons Accessibility and Interaction Fix
**Learning:** Framer Motion components relying on `whileHover` for visual expansion are inaccessible to keyboard users unless paired with `whileFocus`. Furthermore, fixed absolute containers grouping interactive floating elements can inadvertently block users from clicking underlying page content, requiring pointer-events management.
**Action:** Pair `whileHover` with `whileFocus` and use Tailwind's `focus-visible` classes to ensure full keyboard navigation support for Framer Motion interactive elements. Ensure images inside expanding width containers use `shrink-0` to avoid squashing. Manage pointer events on fixed/absolute grouping containers using `pointer-events-none *:pointer-events-auto` so users can interact with content underneath while keeping buttons clickable.
