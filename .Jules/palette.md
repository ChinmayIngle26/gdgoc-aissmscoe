## 2024-03-24 - Stacked Floating Social Buttons Accessibility
**Learning:** When using a fixed flex container to group floating interactive elements (like social overlays), the container's invisible bounding box can block clicks on underlying page content. Additionally, elements expanding on hover (e.g., Framer Motion `whileHover`) often become inaccessible via keyboard navigation if `whileFocus` isn't also provided.
**Action:** Apply Tailwind classes `pointer-events-none` to the container and `*:pointer-events-auto` to its children. Always pair `whileHover` with `whileFocus` for Framer Motion interactive elements, add `focus-visible:ring-2 focus-visible:outline-none` for visual focus indicators, and ensure child images in icon-only buttons with `aria-label` are marked `alt="" aria-hidden="true"`.
