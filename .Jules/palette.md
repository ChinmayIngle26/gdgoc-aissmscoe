## 2024-05-15 - Social Button Container and Focus Improvements
**Learning:** Fixed absolute positioning on multiple floating UI elements can create overlapping "invisible bounding boxes" that block user interaction with the underlying page. Using `pointer-events-none` on the container with `*:pointer-events-auto` on the children safely groups elements without blocking clicks. Additionally, Framer Motion elements requiring hover states (`whileHover`) must explicitly include focus states (`whileFocus` and `focus-visible` classes) to ensure keyboard users can access the same visual feedback.
**Action:** Always check container bounding boxes when implementing floating UI elements to ensure they do not obstruct page interaction. For animated interactive elements, pair `whileHover` with `whileFocus` to maintain accessibility parity.
