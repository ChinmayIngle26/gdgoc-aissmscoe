## 2024-05-15 - ARIA Labels on Framer Motion Interactive Elements
**Learning:** Found that `<motion.button>` elements in interactive components like the mobile navbar hamburger menu lacked basic accessibility features like `aria-label` and `aria-expanded`.
**Action:** When working with Framer Motion elements like `<motion.button>` or `<motion.a>`, always ensure standard HTML accessibility attributes and focus indicators (`focus-visible:ring-2 focus-visible:outline-none`) are applied to support screen readers and keyboard navigation.
