## 2024-06-03 - Floating Social Buttons Accessibility & Layout
**Learning:** Fixed floating containers with invisible bounds can block interactions on underlying elements. Interactive icon-only buttons using Framer Motion animations (like expanding width on hover) are often inaccessible to keyboard users and screen readers due to missing focus states and redundant image alt text. During width transitions, nested images can squash if not handled properly.
**Action:** Applied `pointer-events-none` to the floating container and `*:pointer-events-auto` to its children. Added `whileFocus` to Framer Motion links for keyboard navigation, paired with Tailwind's `focus-visible:ring-2 focus-visible:outline-none`. To prevent squashing during width animations, added `shrink-0` to the nested images. For accessibility, set decorative image `alt=""` and `aria-hidden="true"` when the parent interactive container already has an `aria-label`.
