## 2024-05-25 - Expanding Floating Social Elements Accessibility & Stacking
**Learning:** When using Framer Motion to expand the width of flex elements that are grouped in a fixed container (like social overlays), the container's invisible bounding box can block clicks on the underlying page content. Furthermore, icon-only buttons need explicit focus states (`whileFocus` matching `whileHover`), keyboard focus indicators (`focus-visible:ring-2`), and `shrink-0` on internal images so they aren't compressed during width transitions. Copy-pasted `aria-label` values are common points of failure for accessibility.
**Action:** Applied Tailwind classes `pointer-events-none *:pointer-events-auto` to the fixed flex container. Synced `whileFocus` to `whileHover`, added focus-visible rings, fixed incorrect `aria-label`s, set decorative image `alt` to empty, and added `aria-hidden="true"` to prevent redundant screen reader announcements when the parent `<a>` already has an `aria-label`.
