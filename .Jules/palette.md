## 2024-05-24 - Floating Social Overlay Component Polish
**Learning:** Fixed flex containers mapping bounding boxes over content block interaction underneath. Complex components require robust keyboard handling and strict accessibility compliance. Purely decorative elements must be explicitly hidden when parents map ARIA roles, or they'll trigger repetitive screen reader output. Also noted that nested icons crush during transition without specific flex rules.
**Action:** When building interactive fixed overlays grouped by flex layout, always apply `pointer-events-none` to the parent and reset pointer events (`*:pointer-events-auto`) on children. Always explicitly pair `whileHover` with `whileFocus` in Framer Motion along with appropriate `focus-visible` UI rings. Add `shrink-0` to static-sized children in transitional parents. Set `alt=""` and `aria-hidden="true"` to purely decorative icons enclosed in ARIA labeled interactive elements.
