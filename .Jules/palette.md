## 2024-05-20 - Framer Motion Keyboard Accessibility and Redundant Screen Reader Announcements
**Learning:** For interactive UI components using Framer Motion, animations triggered via `whileHover` are invisible to keyboard-only users. Additionally, interactive components with explicit `aria-label`s containing informative or decorative images result in redundant and confusing screen reader announcements if the images have `alt` text.
**Action:** Always pair Framer Motion's `whileHover` with `whileFocus` for interactive elements to ensure animations play on keyboard focus. Add explicit `focus-visible` styles to indicate focus. If an interactive parent element provides adequate context via `aria-label`, explicitly set `alt=""` on its child images/SVGs to suppress redundant announcements.
