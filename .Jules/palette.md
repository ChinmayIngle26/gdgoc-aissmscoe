## 2025-02-23 - Framer Motion Keyboard Accessibility and Copy-Paste Errors
**Learning:** Using `whileHover` in Framer Motion to reveal text in interactive components creates an accessibility barrier for keyboard users navigating via Tab if not paired with `whileFocus`. Additionally, copying similar components (like floating social buttons) often leads to incorrect `aria-label` values being copied over, misrepresenting the component to screen readers.
**Action:** Always pair `whileHover` with `whileFocus` to ensure animated reveals are accessible via keyboard navigation. Always double-check `aria-label` values to avoid copy-paste errors when creating multiple similar components. Also, any purely decorative child images within a component that already has an `aria-label` providing context should have empty alt text (`alt=""`) and `aria-hidden="true"`.
