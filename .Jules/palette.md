## 2024-05-02 - Copy-paste errors in social buttons and Framer Motion Hamburger Menu Accessibility
**Learning:** When components like `DiscordButton`, `WhatsappButton`, and `LinkedinButton` are duplicated to create variations, `aria-label` and `alt` attributes are easily forgotten, leading to confusing screen reader announcements (e.g., the LinkedIn button announcing itself as "Join Whatsapp Group" and its icon as "Whatsapp Logo"). Also, for complex interactive UI components like Framer Motion hamburger menus, `aria-expanded`, `aria-label`, and `aria-controls` need to be directly tied to the React state variables that control the visual transitions to ensure screen readers correctly interpret the UI state.
**Action:** Always verify `aria-label` and `alt` tags when duplicating components for variations. For custom interactive components like mobile menus, explicitly bind dynamic ARIA attributes (`aria-expanded`, dynamic `aria-label` like "Open menu" / "Close menu") to the component's state to match the visual behavior.
