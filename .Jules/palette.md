## 2023-11-20 - Keyboard Accessibility for Framer Motion Expandable Buttons
**Learning:** For components that expand on hover using Framer Motion (like floating social buttons with `whileHover`), the text inside is hidden to keyboard users navigating via Tab unless `whileFocus` is also added and an explicit focus state is defined (e.g., `focus-visible:ring-2`). Additionally, if an `<a>` element has an `aria-label`, child `<img>` tags for the decorative icon should use `aria-hidden="true"` and `alt=""` to prevent redundant/confusing announcements.
**Action:** When creating or fixing hover-expand animations with framer-motion, always pair `whileHover` with `whileFocus`. Always ensure icon buttons with text have correct `aria-label`s on the wrapper and hide the decorative SVG/img.
