## 2023-10-27 - Framer Motion Accessibility & Flex Shrinking
**Learning:** For UI components using Framer Motion (like floating social buttons), using `whileHover` expands the elements for mouse users, but it fails to trigger via keyboard navigation. Additionally, when animating the width of a flex container containing an image, the image can squash during the transition if not properly styled. Finally, when using fixed overlays for these floating elements, their invisible bounding box can block clicks on underlying page content.
**Action:** Always pair `whileHover` with `whileFocus` to ensure animations are accessible via keyboard navigation. Combine this with Tailwind's `focus-visible:ring-2 focus-visible:outline-none` for clear visual focus indicators. Apply `shrink-0` to the nested image to prevent squashing during width transitions. Use `pointer-events-none` on the fixed container and `*:pointer-events-auto` on its children to prevent interaction blocking. Ensure purely decorative SVG icons within elements that have `aria-label` receive `alt=""` and `aria-hidden="true"`.
