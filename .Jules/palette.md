## 2024-05-26 - Social Overlay Micro-Interactions
**Learning:** Fixed absolute positioning on individual sticky elements makes the layout brittle and misaligned. Additionally, floating interactive elements inside a fixed container can accidentally block clicks on underlying page content. Image scaling inside flex containers animating width causes squashing artifacts unless explicitly told not to shrink.
**Action:** Use a single fixed flex container (`flex-col items-end`) to stack interactive elements. Apply `pointer-events-none` to the container and `*:pointer-events-auto` to its children. This prevents the container's bounding box from blocking clicks while keeping the children clickable. Apply `shrink-0` to images inside animated flex buttons to prevent distortion. Ensure purely decorative SVGs use `alt="" aria-hidden="true"` with interactive elements declaring full context via `aria-label`.
