## 2024-03-24 - Interactive Component Accessibility and Security
**Learning:** Framer Motion components with `whileHover` animations must also include `whileFocus` to ensure the same visual feedback is provided for keyboard users. Additionally, when decorative SVG images inside interactive components like buttons/links are accompanied by an `aria-label` on the parent, the `alt` text of the SVG should be empty (`alt=""`) to prevent redundant screen reader announcements. Finally, all external links (opening in new tabs via `target="_blank"`) require `rel="noopener noreferrer"` to prevent reverse tabnabbing vulnerabilities.
**Action:** Always check `motion` components with hover states for corresponding focus states, combine them with Tailwind's `focus-visible` utilities, strictly manage SVG `alt` tags based on parent `aria-labels`, and consistently enforce secure link attributes.
