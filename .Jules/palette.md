## 2024-05-18 - Keyboard Navigation & Overlay Containers
**Learning:** Animated social floating buttons using Framer Motion (`whileHover`) were inaccessible via keyboard. In addition, when placing these interactive buttons within a fixed flex container acting as an overlay (e.g., bottom-right corner), the invisible bounding box of the container blocks mouse interactions for the underlying page content.
**Action:** Always pair `whileHover` with `whileFocus` (plus `focus-visible:ring-2`) in Framer Motion variants to ensure keyboard users receive the same interactive feedback. When grouping floating action buttons in a fixed container, apply Tailwind classes `pointer-events-none` to the container itself and `*:pointer-events-auto` to its children. This allows users to click "through" the empty space of the container while keeping the buttons clickable.
