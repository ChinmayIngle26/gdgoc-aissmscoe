## 2024-06-15 - Floating Action Buttons Accessibility and Interactivity
**Learning:** Fixed/absolute position flex containers grouping interactive elements (like social buttons on the side) block clicks to the underlying page content. Additionally, elements that expand on hover (like `framer-motion`'s `whileHover`) need corresponding `whileFocus` to be accessible via keyboard, and their internal images need `shrink-0` to avoid squashing during width transitions. Also, pure decorative images inside an `a` tag with an explicit `aria-label` should use `alt="" aria-hidden="true"`.
**Action:** Applied `pointer-events-none` to the fixed container and `*:pointer-events-auto` to its children. Added `whileFocus` alongside `whileHover`, `shrink-0` to the icons, and configured focus rings (`focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-offset-2`). Ensured decorative SVGs have `alt="" aria-hidden="true"`.
