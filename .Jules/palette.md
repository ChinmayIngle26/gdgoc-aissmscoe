## 2024-05-18 - Framer Motion State and ARIA Alignment
**Learning:** When building custom interactive elements with Framer Motion (like hamburger menus or floating toggles), developers often focus entirely on the visual `animate` state and forget to update native accessibility attributes like `aria-expanded` to match the internal React state variables. Additionally, when copy-pasting components (like floating social buttons), `aria-label` and `alt` attributes are frequently missed, leading to misleading screen reader announcements.
**Action:** Always explicitly link React state variables (e.g. `menuOpen`) controlling visual transitions directly to relevant ARIA attributes (e.g. `aria-expanded={menuOpen}`). Double check `aria-labels` and `alt` texts when duplicating similar UI components.
