## 2025-05-22 - Framer Motion Hamburger Menu Accessibility
**Learning:** Adding complex visual animations with Framer Motion often obscures the underlying interactive element's required semantic structure. When styling an icon-only `motion.button` toggle, visual states (like rotating spans) MUST be explicitly mirrored with ARIA states (`aria-expanded`, dynamic `aria-label`) and visual keyboard focus indicators (`focus-visible` ring paired with `whileHover`/`whileFocus` scale animations).
**Action:** When creating or auditing custom animated toggles (like hamburger menus), ensure the underlying `motion.button` retains full native button semantics: dynamically toggle `aria-expanded`, update `aria-label` text based on state, explicitly link `aria-controls` to the collapsible container's ID, and define explicit `focus-visible` focus ring styles to maintain keyboard navigability.
