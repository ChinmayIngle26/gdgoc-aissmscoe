## 2025-06-11 - Social Buttons Accessibility and Keyboard Navigation
**Learning:** Animated flex buttons (like social links) need explicit keyboard focus states (`whileFocus` matching `whileHover`) and focus-visible styling for accessibility. Also, absolute/fixed position containers acting as bounds for right-aligned items can inadvertently block clicks on underlying content; setting `pointer-events-none` on the container and `*:pointer-events-auto` on the children fixes this. Images within components that already have `aria-label` context should have empty alt text (`alt=""`) and `aria-hidden="true"` to prevent redundant screen reader announcements. Finally, icons inside expanding flex containers need `shrink-0` to avoid being squashed during transitions.
**Action:** Always pair `whileHover` with `whileFocus` for Framer Motion interactive elements. Apply `focus-visible:ring-2 focus-visible:outline-none` for visual focus. Use the pointer-events trick for floating element containers.
