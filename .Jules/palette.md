## 2024-05-14 - Expanding Button and Floating Action Button (FAB) Accessibility
**Learning:** Fixed absolute positioned containers blocking clicks underneath due to invisible bounding boxes. Also learned that expanding buttons using `whileHover` in Framer Motion need a matching `whileFocus` to be usable via keyboard navigation, and flex child images need `shrink-0` to avoid horizontal squashing during width animations.
**Action:** When using fixed flex containers for overlay elements, apply `pointer-events-none` to the container and `*:pointer-events-auto` to children. Pair Framer Motion's `whileHover` with `whileFocus` for interactive elements and use `shrink-0` on images inside expanding flex layouts. Combine these with `focus-visible:ring-2 focus-visible:outline-none` for clear keyboard focus indicators.
