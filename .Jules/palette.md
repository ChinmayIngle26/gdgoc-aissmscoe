## 2025-04-23 - Dynamic Accessibility Attributes for Framer Motion Interactive Elements
**Learning:** When building custom interactive elements (like a hamburger menu) controlled by Framer Motion and React state, screen readers miss the context of the visual transition. Native buttons communicate their expanded state implicitly or via simple attributes, but custom animated overlays require explicit, dynamic ARIA bindings to the state variables driving the animations.
**Action:** Always explicitly tie accessibility states (`aria-expanded`, dynamic `aria-label` changing from 'Open' to 'Close', and `aria-controls` referencing the ID of the expanded container) directly to the React state variables controlling the visual transitions. Ensure keyboard focus states (`focus-visible:ring-2`) are present so keyboard users can navigate to these custom elements.
