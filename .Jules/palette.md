## 2024-06-05 - Social Button Accessibility and Animation Polish
**Learning:** Decorative icons inside elements that already have an `aria-label` can cause redundant screen reader announcements if not hidden (`aria-hidden="true"` and `alt=""`). During flex container width animations (like Framer Motion's `whileHover`), child images can squash if they don't have the `shrink-0` class. Keyboard navigation requires `focus-visible` styles to be explicit, and `whileFocus` should match `whileHover` for parity. Lastly, a fixed container for social buttons can block underlying clicks unless it uses `pointer-events-none` with `*:pointer-events-auto` on its children.
**Action:** Always add `aria-hidden="true"` and empty `alt` text to purely decorative icons inside labeled interactive elements. Ensure `shrink-0` is applied to icons within expanding flex containers. Always pair `whileHover` with `whileFocus` and use `focus-visible` for clear keyboard indicators. Use pointer-events utilities on fixed overlay containers.
