## 2024-05-01 - Accessible Framer Motion Interactive Elements
**Learning:** When using `whileHover` on interactive elements like `<a>` or `<button>` to trigger Framer Motion animations (like revealing text or expanding width), the animation is inaccessible to keyboard users unless explicitly paired with `whileFocus`. Additionally, when an interactive container provides context via `aria-label`, any purely decorative icons within it should be hidden from screen readers using `alt=""` and `aria-hidden="true"` to prevent redundant or confusing announcements.
**Action:** Always pair `whileHover` with `whileFocus` for Framer Motion interactive elements, add `focus-visible` classes for visible focus indicators, and ensure child icons of aria-labeled containers are marked as decorative.
