## 2026-04-05 - Framer Motion Keyboard Accessibility and aria-label correctness
**Learning:** Components built with `framer-motion` often use `whileHover` to reveal information (like tooltips or expanded button text), but frequently lack a corresponding state for keyboard users. Furthermore, decorative SVG/Images inside such components can pollute screen reader output if not explicitly hidden with `aria-hidden="true"`. Also, `aria-label` attributes are often blindly copy-pasted when creating similar components (like duplicating a WhatsApp button to make a LinkedIn button).
**Action:** When implementing or reviewing `framer-motion` components, always pair `whileHover` with `whileFocus`. Combine this with `focus-visible:ring-2` to ensure the interaction is visible to keyboard users. Hide any redundant decorative images with `alt="" aria-hidden="true"`. Double check the content of `aria-label` attributes across similar components to prevent copy-paste errors.
