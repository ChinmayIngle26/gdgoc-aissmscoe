## 2024-06-09 - Accessible Framer Motion Social Buttons
**Learning:** Framer Motion components often lack native keyboard focus state handling when only `whileHover` is used, making them inaccessible for keyboard users. Furthermore, interactive components (like social buttons) that contain decorative SVGs/images can cause redundant screen reader announcements if not properly hidden.
**Action:** Always pair `whileHover` with `whileFocus` for Framer Motion interactive elements. Ensure clear visual indicators using `focus-visible:ring-2 focus-visible:outline-none`. For child images inside buttons with `aria-label`, use empty alt text (`alt=""`) and `aria-hidden="true"` to prevent redundant screen reader announcements. Use `shrink-0` on images inside expanding flex buttons to prevent them from squashing during width transitions.
