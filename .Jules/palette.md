## 2024-05-18 - Framer Motion Keyboard Accessibility & Flex Container UX
**Learning:** Framer Motion components that use `whileHover` for visual expansion often lack keyboard accessibility. We must explicitly pair `whileHover` with `whileFocus` to ensure keyboard users get the same interactive experience. Additionally, when a fixed flex container holds floating interactive elements, applying `pointer-events-none` to the container and `*:pointer-events-auto` to the children prevents the invisible bounding box from blocking interactions with the underlying content. Finally, applying `shrink-0` to images within expanding flex containers prevents them from squashing during transitions.
**Action:** Always pair `whileHover` with `whileFocus` on interactive motion components and add `focus-visible:ring-2 focus-visible:outline-none`. Use `pointer-events-none *:pointer-events-auto` for fixed float containers. Use `shrink-0` on fixed-size child elements inside animating flex containers.
